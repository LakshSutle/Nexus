# Implementation Plan - Highly Influential and Action-Driven Reminders

The goal of this task is to change the reminder messages generated by NEXUS so that they are instantly influential, psychologically compelling, and motivate the user to start working on their goals immediately.

## Proposed Changes

We will modify the prompt engineering for the Gemini model in `backend/agents/outreach_agent.py` to generate messages with even greater psychological impact, and update the default fallback messages.

We will upgrade the prompts for:
1. **Velocity Deficit Reminders (`_build_deficit_message`)**: Enhance pattern interrupts, leverage FOMO and identity friction, and offer a friction-free immediate choice.
2. **Deadline Approaching Reminders (`notify_deadline_approaching`)**: Focus heavily on urgent loss aversion, temporal scarcity, and one micro-commitment that takes less than 2 minutes.
3. **Fallback Templates**: Make sure the fallback text matches this high-influence style in case the AI API fails.
